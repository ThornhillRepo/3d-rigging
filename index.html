    Blender Weight Painting

    Your rig moves, but some joints crease, pinch or drag the wrong parts along. Learn how weights really work, paint them while the rig is posed, clean them up and test them in strong poses.

    Start with the warm-upJump to the weight lab

    Learning outcomes

    By the end you will be able to:

    • explain what a weight is and how vertex groups share a vertex;
    • enter Weight Paint with a posable rig and choose the right bone;
    • use Draw, Subtract and Blur with sensible Radius, Strength and Weight;
    • clean weights with Auto Normalize, Normalize All, Clean and Mirror;
    • test joints in poses and use Preserve Volume and the Deform setting;
    • set exact weights in Edit Mode and fix vertices that are left behind.

    What is weighting?

    Weights decide how a mesh bends when the bones move. Four ideas matter most.

    ◐Weights

    A number from 0 to 1 says how much a bone moves each vertex.

    ⬢Vertex groups

    Each deforming bone has a group with the same name.

    ◇Sharing

    A vertex in two groups moves part of the way with each bone.

    ✦Testing

    Pose the joint, paint, then pose it again.

    Good to know

    Built-in tools only

    Everything here uses Blender’s own Weight Paint mode and Weights menu. No add-ons are needed.

    Paint while posed

    Joints look fine when they are straight. Bend the joint first, then paint.

    Save versions

    Save a new version before big clean-ups such as Normalize All or Mirror.

    Using a Mac?

    Save and undo use Cmd, and Alt is labelled Option.

    How to read the keys

    Shift+F hold the keys together
    MthenB press one after the other
    Numpad 1 number pad key
    Alt+Left click mouse action

        For tutors

        Teacher notes

        Purpose and audience

        Part 6 of an interactive Blender series. It follows Part 5 (Rigging) and teaches learners to fix and improve the weights on the rig they built, using Blender’s built-in Weight Paint mode, Weights menu and Armature modifier only. It uses the same layout, progress tracking, searchable reference, review deck and final challenge as the earlier parts.

        The sequence moves from explanation (Learn) through experimentation (weight lab) and analysis (step order, weight problems, which tool) to decision making (scenarios), retrieval practice (review deck, final challenge) and application in Blender (mini project).

        Suggested session plan (one session of about 2 hours)

        Starter (10 min): warm-up quiz, then pose a learner’s Part 5 rig on screen and ask where it looks wrong.

        Demo (25 min): enter Weight Paint with the armature, select bones, fix one elbow with Draw, Subtract and Blur while it is bent, then show Normalize All, Clean and Preserve Volume.

        Explore (25 min): Learn categories and the weight lab goals. Fast finishers try Weight problems and Which tool?

        Student work (50 min): the mini project in Blender. Plenary (10 min): final challenge and printed summary.

        Differentiation and assessment

        Support: use hints, multiple-choice-only mode in the final challenge and the printed cheat sheet. Let learners fix one arm only and mirror it. Stretch: the extension tasks (Preserve Volume, Limit Total, twist bones) and explaining the ratio rule aloud. Evidence: the printed summary, before-and-after screenshots of one joint bent to its limit, and three posed renders.

        Results are self-reported and stored only on the student’s device, so treat them as formative evidence.

        Practical and version notes

        The resource is a single HTML file with no external libraries, so it works offline. Content is based on Blender 4.x with the default keymap. Version notes: selecting bones in Weight Paint has changed several times. In 3.x it was Ctrl-click, in 4.0 Ctrl+Shift-click, and from 4.1 there is a Bone Selection mode in the header (shortcut 3) with Alt-click. The Vertex Groups list always works. From 4.3, brushes are assets, so brush names in the list may differ slightly from the tool names used here.

        The weight lab is a 2D teaching model, not Blender itself. Like Blender’s Armature modifier, it bends each vertex by the ratio of its weights, and a vertex with no weight stays behind. Preserve Volume in the lab is a simplified version of Blender’s dual quaternion method.
